# Play with NLP 🤖

A collection of small NLP experiments and projects to explore various natural language processing techniques and concepts.

## Repository Structure

This repository contains multiple independent NLP experiments, each in its own folder. Each experiment includes:
- **Code**: Implementation files (`.py`)
- **Notebook**: Interactive Jupyter notebook (`.ipynb`) for exploration and visualization
- **README**: Documentation explaining the experiment, approach, and results

## Projects

### 1. [Sentiment Analysis](./experiments/sentiment-analysis/)
Basic sentiment analysis using pre-trained transformers to classify text as positive, negative, or neutral.

### 2. [Text Classification](./experiments/text-classification/)
Multi-class text classification using traditional and modern NLP techniques.

### 3. [Named Entity Recognition](./experiments/named-entity-recognition/)
Extract and classify named entities (persons, organizations, locations) from text.

## Getting Started

### Prerequisites
```bash
pip install -r requirements.txt
```

### Running an Experiment

1. Navigate to the experiment folder
2. Follow the instructions in the experiment's README
3. Run the Jupyter notebook for interactive exploration
